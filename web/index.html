Tile-based and parallel

Triangles are binned into 64×64 pixel tiles. Each tile is rasterized by a single worker thread, so the color and depth buffers need no locks and the image is identical for any thread count. Try the thread slider and the heatmap.

Correct rasterization

Sub-pixel fixed-point edge functions with the top-left fill rule, homogeneous near-plane clipping, perspective-correct interpolation, and screen-space UV derivatives for mip selection.

Physically based shading

Cook-Torrance GGX with metallic/roughness materials, normal mapping, soft PCF shadow maps, sky lighting, and ACES tone mapping, all in C++ fragment "shaders".

Built with C++17, Emscripten and SDL2 (used only to present the finished frame). Spot model by Keenan Crane.
